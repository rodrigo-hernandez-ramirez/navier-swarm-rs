navier-swarm-rs

High-performance swarm robotics with Navier-Stokes inspired fluid dynamics — in Rust 🦀

View on GitHub Download ZIP

What is this?

Rust implementation exploring decentralized swarm behavior using fluid dynamics potentials. Each agent follows APF: v_new = v_old + (F_target + F_fluid + F_swarm) * dt

Run locally

git clone https://github.com/rodrigo-hernandez-ramirez/navier-swarm-rs
cd navier-swarm-rs
cargo run --release

Built by Rodrigo Hernandez — Mérida, MX. Inspired by OpenAI's 10k-agent Navier-Stokes swarm research (Sept 2026).
